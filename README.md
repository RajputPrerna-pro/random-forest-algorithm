# 🌳 Random Forest Algorithm

This repository contains implementations and practical examples of the **Random Forest Machine Learning Algorithm** using Python and Scikit-learn.

The project includes both **Random Forest Classification** and **Random Forest Regression** models with datasets and Jupyter Notebooks.

## 📌 Project Overview

Random Forest is an ensemble machine learning algorithm that combines multiple decision trees to make accurate and reliable predictions.

It can be used for:

* Classification problems
* Regression problems
* Handling complex datasets
* Improving prediction performance
* Reducing overfitting compared with a single Decision Tree

## 🤖 Algorithms Used

### 1. Random Forest Classification

The classification notebook demonstrates how Random Forest can be used to predict categorical outcomes.

Main steps:

1. Load the dataset
2. Explore the data
3. Handle missing values
4. Prepare features and target
5. Split data into training and testing sets
6. Train the Random Forest Classifier
7. Make predictions
8. Evaluate the model using accuracy

### 2. Random Forest Regression

The regression notebook demonstrates how Random Forest can be used to predict continuous numerical values.

Main steps:

1. Load the dataset
2. Explore the dataset
3. Select features and target
4. Split the data
5. Train the Random Forest Regressor
6. Make predictions
7. Evaluate the model using regression metrics

## 📊 Datasets

The repository contains datasets used for practicing Random Forest algorithms:
